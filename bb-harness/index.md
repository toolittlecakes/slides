# Что такое bb: два уровня агентной работы

Адаптивная схема: отдельные экосистемы Codex и Claude рядом с общей рабочей средой bb.

## Верхний harness — рабочая среда

Codex CLI, Codex Desktop и расширение VS Code подключаются к Codex через App Server. Агентный режим Claude Desktop показан отдельным семейством над Claude Code / Agent SDK. bb объединяет несколько движков: Codex, Claude Code, Pi и OpenCode.

## Нижний harness — агентный движок

Движок выполняет собственный агентный цикл, использует инструменты и управляет контекстом. Сплошные стрелки вниз обозначают подключение и передачу контекста; пунктирные вверх — вызовы функций оболочки.

## Что оболочка добавляет агенту

- Действия: инструменты Desktop для терминала, автоматизаций и тредов; команды bb для поиска разговоров, передачи работы и управления терминалами.
- Инструкции: developerInstructions приложения, контекст окружения и инструкции плагинов bb.
- Skills: control-in-app-browser, bb-cli и inline-vis как примеры рецептов работы с возможностями среды.

В контекст передаются описания действий и инструкции. Терминалы, браузер и планировщик остаются сервисами оболочки. Конкретные возможности зависят от режима, флагов, провайдера и подключённых плагинов.

## Композиция

На широком экране обе архитектуры стоят рядом, ниже расположены три карточки с примерами. До 1100 px схема перестраивается в две последовательные сцены; Codex и Claude остаются рядом, движки bb сгруппированы на одном уровне, карточки идут вертикально.
