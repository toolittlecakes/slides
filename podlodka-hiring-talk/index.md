### Кейс 2. Найм классического инженера

Есть готовый игровой репозиторий

В нем заложены проблемы, которые существуют в зрелых проектах:

- Рассинхрон документации
- Архитектура не вмещает новые фичи без рефакторинга
- Микс разных подходов
- Легаси решения, которые ограничивают рефакторинг
- Нет ai-нативности™

Нужно впилить новую фичу

Детектим:

- Как использует ИИ агентов
- Насколько погружается в реализацию
- Может ли найти проблемы
- Понимет как сделать подходящий рефакторинг

Есть этап автоматического анализа решения по чеклистам сразу после отправки

### Главные выводы

- ИИ подсвечивает компетентность (или некомпетентность)

- На сегодняшнем рынке растет толерантность к тестовым
