# Снятие SynthID с картинок gpt-image: SD1.5 img2img vs qwen-zimage

Таблица визуальных результатов эксперимента: пять картинок gpt-image (C2PA + SynthID), два регенерационных ремувера, три уровня strength. Оракул — OpenAI Content Provenance API, один запрос на файл.

## Колонки

- Оригинал (закреплён слева при горизонтальном скролле)
- SD1.5 img2img (noai-watermark, dreamshaper-8, локально на M1 Pro / MPS): 0.05, 0.08, 0.15
- qwen-zimage (remove-ai-watermarks: Qwen-Image-2512 + Lightning + Canny ControlNet + Z-Image face stage, Modal A100-80GB): 0.05, 0.08, 0.156

## Строки на кейс

1. Заголовки колонок (повторяются над каждым кейсом)
2. Уменьшенная картинка целиком, PSNR к оригиналу и вердикт API
3. Центральный кроп 300×300 в масштабе 1:1
4. Комментарий: что видно глазами

## Итог

- qwen-zimage снимает знак на 0.08 у всех пяти при заметно лучшем сохранении деталей
- SD1.5 портит кожу и текст раньше, чем задевает watermark; 5/5 только на 0.15
- Плоская графика чистится при минимальной силе у обоих
- Текст на вывесках — главная жертва любой регенерации

Страница генерируется скриптом `make_gallery.py` из папки эксперимента; миниатюры и кропы встроены base64, полноразмерные JPEG лежат в `assets/` и открываются по клику.
